# Smart Desk

Локальное управление столом Volundr X2DM-SE / CL-103B-G через ESP32-S3 и
Bluetooth-пульт Ulanzi D100H. ESP заменяет штатную панель на UART-разъёме J8;
силовая плата стола продолжает управлять двигателями.

Рабочие функции: шаг и непрерывное движение крутилкой, STOP, сохранённые
SIT/STAND, пределы 72–118 см с компенсацией выбега, восстановление через RST,
переподключение Bluetooth и постоянный журнал UART.

## Состояние проверки

Последний завершённый аппаратный прогон — `df68edc`, проверка от
25 сентября 2026 года. Версия `458e7c6` с постоянным журналом установлена
3 октября: загрузка и доступность журнала подтверждены, NVS сохранён.
[Первый прогон и чтение истории](docs/test-run-2026-10-03.md) завершены:
журнал цел, STEP, SIT снизу и RST видны; нижний предел оказался 71,9 см
вместо 72,0. Последний UNKNOWN по времени согласуется с выключением питания;
его код пока не расшифрован.
Для кода журнала прошли шесть наборов host-тестов с UBSan
и сборки всех восьми режимов ESP-IDF 6.1. Это не заменяет проверки задержек
STOP, записи flash и питания на устройстве.

## Репозиторий

- `firmware/` — ESP-IDF, независимые компоненты и host-тесты.
- `tools/` — проверка сборок, чтение журнала, разбор захватов и HID-диагностика.
- `docs/` — текущие инструкции и история измерений.
- `captures/raw/` — исходные записи UART и логического анализатора.
- `photo/` — фотографии плат и заводской инструкции.
