# Smart Desk

Smart Desk заменяет штатную панель стола Volundr X2DM-SE на ESP32-S3 и пульт Ulanzi D100H.
Контроллер CL-103B-G продолжает управлять двигателями.
ESP передаёт команды через UART и сохраняет историю во flash.
Для работы не нужны компьютер, сеть или облачный сервис.

## Возможности

- Одиночный шаг примерно на 1 см и продолжительное движение крутилкой.
- Отмена движения нажатием крутилки.
- Сохранение высот SIT и STAND в ESP.
- Программные пределы 72–118 см с компенсацией выбега.
- Блокировка обычного управления при неизвестном ответе стола.
- Калибровка через удержание SIT+STAND в течение 10 с.
- Сохранённая привязка Bluetooth и повторное подключение D100H.
- Постоянный журнал команд, ответов, пресетов и причин остановки.

Рабочая прошивка не выводит live-диагностику в USB.
После ошибки историю читают из flash через загрузчик ESP.

## Начало работы

1. Сверьте плату и проводку с [инструкцией подключения](docs/esp32-board.md).
2. Прочитайте [условия эксплуатации](docs/safety.md).
3. Соберите и запишите [рабочую прошивку](firmware/README.md).
4. Подключите D100H по [инструкции управления](docs/ulanzi-d100h.md).
5. Выполните [аппаратный прогон](docs/single-run-test.md).

**Перед подключением USB отсоедините J8-1 → ESP 3V3.**
Штатная панель и TX ESP не должны одновременно передавать команды на J8-2.

## Состояние проекта

Это прототип для исследованного стола и указанного профиля D100H.
Совместимость с другими контроллерами не подтверждена.
Программные проверки не заменяют измерения задержек, питания и механического выбега.

Прошивка `b5058cb` записана в ESP 2026-10-03.
Проверка загрузки описана в [истории измерений](docs/measurements.md#m-014-установка-версии-b5058cb).
Новые записи пресетов и причины STOP требуют аппаратного прогона.
Предыдущий прогон обнаружил нижнюю конечную высоту 71,9 см при настройке 72,0 см.
Это отклонение остаётся открытым.

## Структура репозитория

| Каталог | Содержимое |
|---|---|
| `firmware/components/` | Компоненты протокола, управления и журнала |
| `firmware/main/` | Адаптеры ESP-IDF и точки входа |
| `firmware/tests/` | Проверки компонентов на компьютере |
| `tools/` | Сборка, чтение flash и разбор захватов |
| `docs/` | Инструкции, справочники и результаты измерений |
| `captures/raw/` | Исходные UART-записи и дампы |
| `photo/` | Фотографии оборудования и заводской инструкции |

Основная ветка — `main`.
Прежняя основная ветка сохранена как `codex/main-before-journal`.
Файлы сборки и настройки конкретного компьютера не хранятся в Git.
