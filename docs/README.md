## Термины

Используйте одно значение каждого термина.

| Термин | Значение |
|---|---|
| ESP | Плата ESP32-S3 с прошивкой Smart Desk |
| Стол | Механизм стола и его силовой контроллер CL-103B-G |
| Штатная панель | Заводской пульт, подключаемый к J8 |
| D100H | Bluetooth-пульт Ulanzi D100H |
| Кадр | Восемь байтов протокола UART |
| Высота | Значение из кадра стола; оно может отличаться от измерения рулеткой |
| Пресет | Высота SIT или STAND, сохранённая в NVS ESP |
| STEP | Автономная команда одиночного шага |
| HOLD | Команда продолжительного движения, которую ESP повторяет |
| IDLE | Команда прекращения удержания; она не подтверждает физическую остановку |
| STOP | Запрос отмены в программе ESP; отдельной UART-команды STOP нет |
| Выбег | Движение механизма после прекращения HOLD |
| Калибровка | Спуск до RST и ожидание стабильной высоты |
| Привязка | Данные Bluetooth bond в NVS |
| Журнал | Кольцо записей в разделе flash `desk_log` |
| Дамп | Файл с прочитанными байтами раздела `desk_log` |
| UART | Последовательный интерфейс между ESP и столом |
| NVS | Хранилище настроек ESP-IDF во flash |
| Телеметрия | Данные высоты, флагов и статуса от стола |

## Правила текста

ASD-STE100 задаёт правила для английского языка.
Проект использует русскую адаптацию [его принципов](https://www.asd-ste100.org/STE_faq.html).
Правила процедур также согласованы с [руководством Google](https://developers.google.com/style/procedures).

- Пишите короткие предложения.
- Описывайте одно действие в каждом шаге процедуры.
- Указывайте условие до действия, которое зависит от него.
- Используйте повелительную форму в инструкциях.
- Сохраняйте имена команд и событий без перевода.
- Разделяйте установленный факт, расчёт и предположение.
- Указывайте версию и дату для результата измерения.
- Не называйте программную проверку аппаратным подтверждением.
- Вводите определение термина до его первого неоднозначного использования.
- Ссылайтесь на основной справочник вместо повторения его таблиц.
