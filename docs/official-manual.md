# Штатная инструкция стола

Документ описывает штатную панель X2DM-SE и контроллер CL-103B-G.
Источники — фотографии инструкции и шильдика, предоставленные 2026-09-14:

Это конспект документа производителя.
Управление через ESP описано в [инструкции D100H](ulanzi-d100h.md).
Сохраните различия между печатной инструкцией и измерениями конкретного стола.

## Контроллер

| Поле шильдика | Значение |
|---|---|
| Model | CL-103B-G |
| Input / Output | 29 V DC / 29 V DC |
| Prod. Date | 25/01 |
| Duty cycle | 2 min on / 18 min off |
| Применение | Linear Actuator; только в помещении |

Разъёмы корпуса: M1, M2, DC IN и DC OUT.
Не используйте DC OUT 29 В для питания ESP.

## Калибровка штатной панелью

Выполните калибровку при неправильной высоте или после замены ножек.
Сначала устраните препятствия и неисправности соединений.
Для подключения штатной панели выключите питание и отключите TX ESP от J8-2.
Не соединяйте два передатчика параллельно.

1. В нижнем положении или при ошибке удерживайте DOWN около 5 секунд до RST.
2. Продолжайте удержание DOWN до завершения процедуры.
3. При необходимости остановки отпустите DOWN. Повторное нажатие продолжает сброс.
4. Дождитесь подъёма примерно на 10 мм, сигнала и отображения минимальной высоты.

Инструкция описывает после запуска два сигнала, затем `8.8.8` и текущую высоту.
Измеренный UART сброса приведён в [протоколе](protocol.md).
Калибровка через D100H использует другое сочетание кнопок.

## Кнопки штатной панели

| Кнопка | Короткое нажатие | Удержание |
|---|---|---|
| UP | Шаг вверх 10 мм | Непрерывный подъём |
| DOWN | Шаг вниз 10 мм | Непрерывный спуск |
| STAND | Вызов высоты стоя | 5 секунд: сохранить высоту; два мигания |
| SIT | Вызов высоты сидя | 5 секунд: сохранить высоту |
| STAND+SIT+UP | — | 5 секунд: включить или выключить детский замок LOC |
| DOWN+UP | — | 5 секунд: открыть настройки |

## Настройки P00–P06

1. Удерживайте DOWN+UP 5 секунд.
2. Выберите параметр короткими UP/DOWN.
3. Нажмите STAND для редактирования.
4. Измените значение кнопками UP/DOWN.
5. Нажмите STAND для подтверждения и возврата в меню.

После 5 секунд без действий система сохраняет изменения и выходит.

| Код | Параметр | Диапазон по инструкции | По умолчанию |
|---|---|---|---|
| P00 | Единицы | 0: см; 1: дюймы | 0 |
| P01 | Минимальная высота | 73 см … P02−10 см, шаг 1 см | 73 см |
| P02 | Максимальная высота | P01+10 см … 122 см, шаг 1 см | 122 см |
| P03 | Толщина столешницы | 0,0 … 10,0 см; влияет на показание высоты | 0,0 |
| P04 | Чувствительность при подъёме | 0: выключено; 1–10: включено | 5 |
| P05 | Чувствительность при спуске | 0: выключено; 1–10: включено | 5 |
| P06 | Зуммер | 0: выключен, кроме аварий; 1: включён | 1 |

Для P04/P05 большее число означает меньшую чувствительность.
Примечание P02 в печатной таблице противоречиво.
Разница не менее 10 см следует из диапазонов P01/P02; это интерпретация таблицы.

D100H не изменяет эти параметры.
Диапазон инструкции 73–122 см, наблюдаемый диапазон стола 70–120 см и пределы ESP 72–118 см имеют разные источники.

## Ошибки штатной панели

| Код | Описание производителя |
|---|---|
| E01 | Обрыв двигателя 1 |
| E02 | Обрыв цепи двигателя 2; только CL103B |
| E03 | Перегрузка двигателя 1 |
| E04 | Перегрузка двигателя 2; только CL103B |
| E05 | Не подключён разъём датчика Холла двигателя 1 |
| E06 | Не подключён разъём датчика Холла двигателя 2; только CL103B |
| E08 | Препятствие |
| E09 | Большое расхождение положений |
| E10 | Высокое напряжение |
| E11 | Низкое напряжение |
| E12 | Обрыв цепи датчика Холла двигателя 1 |
| E13 | Обрыв цепи датчика Холла двигателя 2; только CL103B |
| E14 | Защита от перегрузки |

E07 отсутствует в приложенной таблице.
Эти коды не сопоставлены с UART-кадрами ESP.
Не объявляйте кадр `03 08 …` ошибкой E08 только по одному байту.

При ошибке инструкция описывает два сигнала и блокировку.
После устранения причины два сигнала обозначают восстановление.
Для большинства ошибок указаны проверка соединений, DOWN 5 секунд или перезапуск питания.
Для E08 сначала проверьте препятствия. При ложном срабатывании проверьте P04/P05.
Для E05/E06/E11 текст предлагает проверить разъёмы датчиков Холла.
Ссылка на датчики при E11 сохранена как написано; её причина не установлена.

## Сон и тепловая защита

После 30 секунд без действий дисплей гаснет.
Первое нажатие пробуждает панель без движения.
Измерения подтвердили это для UP; остальные кнопки отдельно не проверены.
При замене панели ESP продолжает посылать IDLE, поэтому отдельный WAKE не требуется.

Бумажная инструкция описывает HOT после 4 минут непрерывной работы в 18-минутном периоде.
При HOT кнопки блокируются.
Восстановление описано через 18 минут либо после перезапуска питания.
Шильдик задаёт более строгое ограничение: 2 минуты работы и 18 минут отдыха.
Соблюдайте шильдик. Не используйте перезапуск для обхода отдыха двигателя.

Детский замок LOC включается и выключается удержанием STAND+SIT+UP 5 секунд.
ESP не реализует меню или детский замок штатной панели.
