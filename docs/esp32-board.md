# Плата ESP32-S3

По фотографиям [лицевой](../photo/YD-ESP32-23_front.jpeg) и
[обратной](../photo/YD-ESP32-23_back.jpeg) стороны идентифицирована плата:

```text
YD-ESP32-23 V1.1 / 2022-V1.3
ESP32-S3-WROOM-1-N16R8
16 МБ flash, 8 МБ Octal PSRAM
```

На плате два USB-C: `COM` через CH343P и native `USB` самого ESP32-S3. Для
первого запуска используется `COM`, чтобы логи UART0 не занимали выбранные
линии стола.

## Выбор GPIO

Для первого пассивного захвата выбраны:

| GPIO | Назначение | Режим |
|---:|---|---|
| 17 | слушать J8-2, панель → основная плата | RX-only, floating |
| 18 | слушать J8-3, основная плата → панель | RX-only, floating |

Для конечной замены пульта предполагается GPIO17=TX к J8-2 и GPIO18=RX от
J8-3. Эта конфигурация уже проверена в рабочем прототипе; обе линии подключены
напрямую, без внешних последовательных резисторов 4,7 кОм.

## Питание рабочего прототипа

ESP получает питание `3.3V` с `J8-1` непосредственно на пин `3V3`, земля — с
`J8-4`. BLE и управление столом при таком питании работают нормально, brownout
и самопроизвольные reset в обычной работе не наблюдались. При этом на основной
плате слышен очень тихий электрический треск, отсутствующий при USB-питании ESP;
запланирован тест с 470 мкФ между 3V3 и GND возле ESP. Для прошивки через USB
питание `J8-1` отключается, чтобы не соединять два источника без развязки.

Не используются:

- GPIO35/36/37 — внутренняя Octal flash/PSRAM у N16R8;
- GPIO43/44 — UART0, CH343P и светодиоды TX/RX;
- GPIO19/20 — native USB D−/D+;
- GPIO48 — встроенный WS2812 RGB;
- GPIO0/3/45/46 — загрузочные/strapping контакты.

Первичный источник pinout и ограничений — репозиторий производителя
[VCC-GND Studio YD-ESP32-S3](https://github.com/vcc-gnd/YD-ESP32-S3).

## Проверенная сборка

- Framework: ESP-IDF 6.1.
- Target: `esp32s3`.
- Результат: read-only sniffer успешно собран 2026-09-14.
- Размер приложения: `0x305b0` байт (около 193 КиБ).
- TX физически не назначен ни одному UART.
- Прошивка записана через CH343/COM, хэш проверен; загрузка на ESP32-S3 rev 0.2
  подтверждена журналом `read-only sniffer; GPIO17/GPIO18 are RX inputs`.
