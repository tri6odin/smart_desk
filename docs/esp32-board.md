# Плата и подключение

Рабочая цель сборки — ESP32-S3-WROOM-1-N16R8.
Модуль содержит 16 МБ flash и 8 МБ Octal PSRAM.
Прошивка не использует PSRAM.

Сверьте плату с [лицевой](../photo/YD-ESP32-23_front.jpeg) и [обратной](../photo/YD-ESP32-23_back.jpeg) фотографиями.
Название DEV-KIT-N16R8 не определяет распиновку клона.
Проверяйте маркировку GPIO и контактов питания на своей плате.

## Проводка

Нумерация J8 соответствует [фотографии штатной панели](../photo/IMG_3957.jpeg).
Контакты перечислены сверху вниз в ориентации этой фотографии.

| Контакт J8 | Контакт ESP | Назначение |
|---|---|---|
| J8-1, 3.3V | 3V3 | Питание ESP без USB |
| J8-2 | GPIO17, TX | Команды ESP → стол |
| J8-3 | GPIO18, RX | Ответы стола → ESP |
| J8-4, GND | GND | Общая земля |

UART работает на 9600 бод, 8N1.
В исследованном прототипе линии подключены напрямую.
Внешние резисторы 4,7 кОм не установлены.
J6 DATA/SCL не соединены с сигнальными контактами J8.
Не используйте J6 вместо J8.

## Подключение для обычной работы

1. Отключите питание стола и USB ESP.
2. Отсоедините штатную панель от командной линии J8-2.
3. Подключите GPIO17, GPIO18 и GND по таблице.
4. Подключите J8-1 к ESP 3V3.
5. Изолируйте соединения.
6. Включите стол.

## Подключение для USB

1. Остановите стол.
2. Снимите питание перед изменением проводки.
3. Отсоедините J8-1 от ESP 3V3.
4. Подключите USB ESP.

GPIO17, GPIO18 и общая земля могут оставаться подключёнными.
Выключение стола из розетки не заменяет отсоединение J8-1.
USB может подать питание обратно в цепь стола.
Не соединяйте оба источника питания через 3V3.

Конденсатор между ESP 3V3 и GND можно оставить подключённым.
После разрыва J8-1 он должен оставаться на стороне ESP.
У электролитического конденсатора подключите «+» к 3V3 и «−» к GND.
Изолируйте выводы.

## Ограничения платы

GPIO17 и GPIO18 не относятся к линиям USB или Octal-памяти.
GPIO35, GPIO36 и GPIO37 на N16R8 заняты Octal-памятью.
GPIO19 и GPIO20 используются native USB.
Не переносите UART на эти контакты без проверки схемы.

На исследованной YD-плате есть COM через CH343P и native USB.
Имя serial port зависит от платы, разъёма и компьютера.
Не используйте старое имя порта без проверки.
Количество контактов гребёнки определяется конкретной dev-платой.

## Проверенное питание и открытые вопросы

Прототип работал от J8-1 с Bluetooth и прямыми UART-линиями.
Запас по току и просадки напряжения не измерены.
При таком питании наблюдался тихий треск основной платы.
При USB-питании треск отсутствовал.
Результат проверки с локальными 470 мкФ не зарегистрирован.

На выходе J4 с маркировкой 5V измерено 6,45 В.
Этот выход не используется для питания ESP.
Измерения приведены в [M-002 и M-009](measurements.md).
