# ESP32-S3: плата и подключение

Цель сборки — ESP32-S3-WROOM-1-N16R8: 16 МБ flash, 8 МБ Octal PSRAM.
PSRAM в текущей конфигурации отключена. Фотографии исследованной платы:
[лицевая сторона](../photo/YD-ESP32-23_front.jpeg),
[обратная сторона](../photo/YD-ESP32-23_back.jpeg).
Название DEV-KIT-N16R8 само по себе не определяет расположение контактов клона:
подключение сверяется по маркировке GPIO и питания на конкретной плате.

## Рабочая проводка

Нумерация J8 — сверху вниз в ориентации
[фотографии панели](../photo/IMG_3957.jpeg).

| Контакт стола | Контакт ESP | Назначение |
|---|---|---|
| J8-1, 3.3V | 3V3 | Питание при работе без USB |
| J8-2 | GPIO17, TX | Команды ESP → стол |
| J8-3 | GPIO18, RX | Ответы стола → ESP |
| J8-4, GND | GND | Общая земля |

UART: 9600 бод, 8N1, линии подключены напрямую. Внешних резисторов 4,7 кОм
в проверенном прототипе нет. Штатная панель отключена от командной линии.
Площадки J6 DATA/SCL не соединены с UART J8 и для этого подключения не подходят.

## USB и питание

Перед USB отсоединить **J8-1 → ESP 3V3**. Отключение стола от розетки не
заменяет разрыв этого провода: USB может подать питание обратно в цепь стола.
UART и общая земля могут оставаться подключёнными для наблюдения при питании
ESP от USB. Перекоммутацию выполнять при снятом питании.

Конденсатор, установленный между 3V3 и GND ESP, и его землю для USB отключать
не требуется. Он должен оставаться на стороне ESP после разрыва J8-1.
У электролитического конденсатора «+» подключается к 3V3, «−» к GND;
соединения необходимо изолировать.

Питание от J8-1 проверено в обычной работе, но запас по току и просадки не
измерены. Зафиксирован тихий треск основной платы, исчезающий при USB-питании.
Результат предложенной проверки с локальными 470 мкФ не записан;
нельзя считать этот вопрос закрытым. На J4 с маркировкой 5V измерено 6,45 В:
этот выход для ESP не используется.

## Контакты платы

GPIO17/18 выбраны отдельно от USB и линий памяти. GPIO35/36/37 на N16R8
заняты Octal-памятью; GPIO19/20 используются native USB. Не переносить UART
на них без проверки схемы и конфигурации.

На сфотографированной YD-плате есть COM через CH343P и native USB.
Доступный serial port зависит от разъёма и конкретной платы; старое имя
`/dev/cu.usbmodem…` нельзя считать постоянным.

Для монтажа нужны плата N16R8, четыре изолированных провода, подходящий
разъём J8 и изоляция соединений. Число контактов гребёнки определяется
конкретной dev-платой, а не обозначением модуля N16R8.
