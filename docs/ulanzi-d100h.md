# Управление через D100H

Эта инструкция относится к рабочему режиму ble-controller и исследованному профилю Ulanzi D100H.
Другой профиль Ulanzi Studio может передавать другие HID-коды.
Значение терминов приведено в [указателе документации](README.md#термины).

## Обычные действия

| Действие | Результат |
|---|---|
| Сделайте один медленный щелчок крутилки | Стол выполняет STEP примерно на 1 см в выбранную сторону. |
| Продолжайте вращать крутилку | ESP передаёт HOLD в выбранную сторону. |
| Прекратите вращение | Через 350 мс без новых сигналов ESP прекращает HOLD. Затем возможен выбег. |
| Нажмите крутилку | ESP отменяет активное движение и передаёт IDLE. |
| Поверните крутилку против движения | ESP отменяет движение. Для обратного хода нужен новый жест после остановки. |
| Коротко нажмите и отпустите SIT или STAND | Стол движется к сохранённой высоте. Во время движения кнопка отменяет текущую цель. |
| Удерживайте SIT или STAND не менее 4,5 с, затем отпустите | ESP сохраняет текущую устойчивую высоту. |
| Удерживайте SIT+STAND вместе 10 с | ESP запускает калибровку. |
| Выполните новое действие при калибровке | ESP отменяет процедуру. |
| Удерживайте PLAY/PAUSE 5 с | ESP выдаёт STOP, удаляет текущую привязку и начинает поиск Bluetooth. |

Один физический щелчок может передать два HID-сообщения.
ESP ждёт 300 мс для выбора STEP.
Третье сообщение того же направления выбирает HOLD без ожидания конца окна.
UART-writer передаёт команды каждые 100 мс.
События не образуют очередь будущих движений.

После HOLD требуется тишина ввода 500 мс и стабильная высота.
Для продолжения в прежнюю сторону нужны три одинаковых кадра.
Для обратного направления нужны пять одинаковых кадров.
IDLE не гарантирует мгновенную остановку или отмену автономного STEP.

## Высоты и сохранение пресетов

| Настройка | Значение |
|---|---:|
| SIT по умолчанию | 80,0 см |
| STAND по умолчанию | 115,0 см |
| Программный минимум | 72,0 см |
| Программный максимум | 118,0 см |
| Минимальная разница STAND−SIT | 10,0 см |
| Компенсация выбега вверх | 2,5 см |
| Компенсация выбега вниз | 2,0 см |
| Допустимый диапазон телеметрии | 70,0–120,0 см |

Рабочие пресеты могут отличаться от значений по умолчанию.
Читайте текущую пару в записи PRESETS нужного запуска.
Значения NVS не заменяются при обычной прошивке.

Чтобы сохранить высоту:

1. Переместите стол к выбранной высоте.
2. Дождитесь физической остановки и устойчивой телеметрии.
3. Удерживайте выбранную кнопку SIT или STAND не менее 4,5 с.
4. Отпустите кнопку.
5. Проверьте новую цель коротким нажатием этой кнопки.

Сохранение разрешено в диапазоне 72–118 см.
Разница STAND−SIT должна оставаться не менее 10 см.
Успешное изменение создаёт SAVE_SIT или SAVE_STAND со старой и новой высотой.
Сохранение того же значения не пишет NVS или журнал.
Отклонённая попытка не создаёт событие SAVE.

Пресеты независимы от пределов ручного движения.
Для верхнего предела HOLD прекращается около 115,5 см.
Для нижнего предела HOLD прекращается около 74,0 см.
Расчёт учитывает ожидаемый выбег, но не гарантирует точность при любой нагрузке.
STEP разрешён, если весь шаг помещается в программные пределы.
В пределах ±1 см от пресета новое движение к нему не запускается.

## Блокировка и калибровка

Неизвестный корректный кадр блокирует обычные команды в обоих направлениях.
ESP продолжает передавать IDLE каждые 100 мс.
Обычная высота после ошибки не снимает блокировку.
POWER_OFF также сохраняет эту блокирующую политику.

Чтобы запустить калибровку:

1. Проверьте пространство до физического минимума стола.
2. Устраните физическую причину ошибки.
3. Удерживайте SIT и STAND вместе 10 с.
4. Дождитесь RST и стабильной высоты.

ESP передаёт DOWN_HOLD без остановки по числовой высоте.
Во время этого спуска UNKNOWN сохраняется в журнале и не прекращает DOWN.
Точный RST прекращает DOWN.
Затем ESP ждёт три одинаковых свежих кадра высоты.
Только после этого обычное управление возвращается.

| Ограничение | Значение |
|---|---:|
| Максимальное ожидание RST при DOWN | 60 с |
| Максимальное ожидание высоты после RST | 10 с |

Тайм-аут сохраняет блокировку.
Новое событие ввода отменяет процедуру.
Если ошибка уже зафиксирована, отмена сохраняет блокировку.
После прерывания жеста отпустите кнопки перед следующим действием.

Для восстановления штатной панелью отсоедините ESP от командной линии.
Выполните [процедуру изготовителя](official-manual.md#калибровка-штатной-панелью).
После устранения ошибки верните ESP.
При запуске локальная блокировка сбрасывается.
Оставшаяся ошибка снова заблокирует управление после получения её кадра.
Перезапуск ESP не устраняет неисправность стола.

Долгое нажатие крутилки не запускает калибровку.
Исследованный D100H передаёт мгновенные press/release при физическом удержании крутилки.

## Bluetooth

Привязка хранится в NVS.
Для повторного подключения разбудите уже сопряжённый D100H.
После удаления привязки включите pairing нижней кнопкой пульта.
Потеря Bluetooth отменяет цель и создаёт запрос STOP.
ESP возвращается к поиску пульта.
Erase-flash удаляет привязку и пресеты.

Исследованный пульт называется Ulanzi Dial или KEHWIN.
VID равен FFF1; PID равен 0082.
Consumer Control использует report ID 2 и двухбайтовый usage little-endian.
Отпускание передаёт `00 00`.

| Действие | Байты |
|---|---|
| Вверх | `E9 00` |
| Вниз | `EA 00` |
| Нажатие крутилки | `E2 00` |
| SIT | `B6 00` |
| STAND | `B5 00` |
| PLAY/PAUSE | `CD 00` |

Для другого профиля сначала используйте лабораторный ble-logger.
Этот режим выводит HID-данные в USB и передаёт только IDLE на UART.
Он не входит в рабочую прошивку.

## Записи управления

Причина остановки сохраняется вместе с IDLE.
Источник SIT/STAND сохраняется после отмены движения.
Отмена активного STEP записывается даже после скрытого IDLE импульса.
Подписи и ограничения приведены в [справочнике журнала](log-reference.md).
