# Управление через Ulanzi D100H

Описание относится к production-режиму `ble-controller` и измеренному
профилю D100H. Другой профиль Ulanzi Studio может выдавать другие HID-коды.

## Действия

| Действие | Результат |
|---|---|
| Медленный отдельный щелчок вверх/вниз | Штатный автономный STEP примерно на 1 см |
| Продолжительное вращение | HOLD в выбранную сторону |
| Прекратить вращение | Через 350 мс без reports прекращается HOLD; далее механический выбег |
| Нажать крутилку | STOP, отмена активной цели |
| Повернуть против текущего движения | STOP; для обратного хода нужен новый жест после остановки |
| Коротко нажать и отпустить SIT/STAND | Движение к сохранённой высоте; во время движения — остановка |
| Удержать SIT или STAND не менее 4,5 с и отпустить | Сохранить текущую устойчивую высоту |
| Удержать SIT+STAND вместе 10 с | Запустить калибровку |
| Новое нажатие или вращение при калибровке | Отменить её |
| Удержать PLAY/PAUSE 5 с | STOP, удалить привязку текущего пульта, начать поиск BLE |

Один физический щелчок может дать два reports. Поэтому прошивка ждёт 300 мс
перед STEP; третий report того же направления запускает HOLD сразу.
Отправка команды происходит в цикле UART с периодом 100 мс.
События во время STEP и выбега не образуют очередь будущих перемещений.

После HOLD нужны 500 мс тишины ввода и стабильная высота: три одинаковых
кадра для продолжения в прежнюю сторону, пять для реверса.
IDLE прекращает HOLD, но не гарантирует мгновенную остановку механики или
отмену уже запущенного автономного STEP.

## Высоты

Пресеты по умолчанию: SIT **80,0 см**, STAND **115,0 см**. В NVS могут быть
другие значения: в последней аппаратной проверке SIT был **81,0 см**.
При успешной перезаписи журнал хранит SAVE_SIT/SAVE_STAND с прежней и новой
высотой; при запуске — исходный снимок PRESETS. Сохранение той же высоты
не создаёт записи. Сохранение разрешено на неподвижном столе со свежей устойчивой телеметрией,
в диапазоне **72–118 см**, при разнице STAND−SIT не менее **10 см**.

Пресеты независимы от пределов ручного движения. Для HOLD используется
компенсация выбега: **2,5 см вверх**, **2,0 см вниз**. У границ команда
снимается на 115,5 и 74,0 см соответственно. Это расчёт ожидаемой конечной
высоты, а не гарантия точности при любой нагрузке. STEP разрешён, только если
весь шаг помещается в пределы. Телеметрия 70–120 см допустима, чтобы стол
мог вернуться внутрь рабочего диапазона. В пределах ±1 см от пресета
движение не запускается.

## Ошибка и калибровка

Неизвестный валидный ответ стола блокирует обычные команды при любом
направлении движения. ESP продолжает передавать **IDLE каждые 100 мс**.
Обычная высота после ошибки сама по себе блокировку не снимает.

Для восстановления удерживать SIT+STAND 10 секунд. ESP передаёт DOWN_HOLD,
не используя высоту как условие остановки. Неизвестные ответы во время
этого спуска сохраняются в журнале, но не прерывают калибровку.

Точный ответ RST прекращает DOWN. Затем ESP ждёт три стабильных свежих
кадра высоты, и только после этого возвращает обычное управление.
На DOWN отведено 60 секунд, на телеметрию после RST — 10 секунд;
тайм-аут оставляет стол заблокированным.

Любое новое действие пульта отменяет процедуру. Если ошибка была зафиксирована,
блокировка остаётся. Незавершённое удержание SIT+STAND не вызывает пресеты;
после прерывания нужно отпустить кнопки перед новым действием.

Альтернатива — отключить ESP, устранить причину ошибки и выполнить сброс
[штатным пультом](official-manual.md), затем вернуть ESP. При перезапуске
локальная блокировка сбрасывается; оставшаяся ошибка снова заблокирует
управление, когда придёт её кадр. Перезапуск не исправляет неисправность стола.

Долгое нажатие крутилки не используется: измеренный D100H передаёт мгновенные
press/release, даже когда ручку физически продолжают держать.

## Bluetooth

Привязка хранится в NVS и переживает обычную прошивку. Для reconnect достаточно
разбудить уже сопряжённый D100H. После удаления bond через PLAY/PAUSE перевести
пульт в pairing нижней кнопкой. Потеря BLE отменяет цель и выдаёт STOP;
прошивка возвращается к поиску. `erase-flash` удаляет привязку и пресеты.

Измеренные Consumer Control reports: ID 2, little-endian usage, отпускание
`00 00`. Пульт определяется как Ulanzi Dial / KEHWIN, VID `FFF1`, PID `0082`.

| Действие | Байты |
|---|---|
| Вверх | `E9 00` |
| Вниз | `EA 00` |
| Нажатие крутилки | `E2 00` |
| SIT | `B6 00` |
| STAND | `B5 00` |
| PLAY/PAUSE | `CD 00` |

Для другого профиля сначала использовать режим `ble-logger`: он выводит
HID-reports через USB и передаёт столу только IDLE. Инструменты прежних
захватов через Mac в текущий репозиторий не входят.
