# Исходные захваты

Каталог `raw/` хранит данные исследования и опубликованный аппаратный прогон.
Это исходные свидетельства, а не файлы сборки.
Не изменяйте их при обновлении декодера или документации.

| Файлы в raw | Опыт |
|---|---|
| `00_j8_power_on_idle.*` | Включение и IDLE |
| `01_j8_up_500ms.*`, `02_j8_down_short.*` | Удержание UP/DOWN и отпускание |
| `03_j8_sit.*`, `04_j8_stand.*` | Вызов штатных пресетов |
| `05_j8_sleep_first_up.*`, `06_j8_sleep_wake_then_up.*` | Сон и пробуждение |
| `07_j8_up_click_awake.*` | Одиночный UP_STEP |
| `08_j8_clicks_98cm.*`, `08_j8_clicks_105cm.*` | Шаги ниже и выше 100 см |
| `09_j8_stand_115cm.*`, `10_j8_stand_recall_115cm.*` | Сохранение и вызов STAND |
| `11_j8_sit_80cm.*`, `12_j8_sit_recall_80cm.*` | Сохранение и вызов SIT |
| `13_j8_rst_uart.log`, `13_j8_rst_uart.raw.log` | Калибровка штатной панелью |
| `14_20261003_production_journal.bin`, `.txt` | Первый журнал после снятия питания; [отчёт](../docs/test-run-2026-10-03.md) |

`.sr` содержит отсчёты PulseView. `.pvs` содержит настройки просмотра и не заменяет отсчёты.
В захватах анализатора D0 подключён к J8-2, D1 к J8-3.
Земля общая; VCC анализатора не подключён.
Частота захвата 1 МГц, декодирование UART 9600/8N1.

Из корня репозитория:

```sh
python3 tools/decode_sr.py captures/raw/00_j8_power_on_idle.sr
```

Утилита поддерживает формат этих файлов: `logic-1-1`, D0/D1.
Для другой частоты укажите `--sample-rate`.
Это не универсальный конвертер всех форматов PulseView.

`.bin` постоянного журнала имеет другой формат.
Читайте его по [инструкции журнала](../docs/persistent-journal.md).
Текст первого прогона сохранён как выдан старым декодером; новые подписи не меняют исходный файл.

Новый дамп публикуйте только с согласия владельца истории.
Храните локальный исходник до редактирования копии или текстового фрагмента.
Выводы по кадрам приведены в [протоколе](../docs/protocol.md), условия опытов — в [измерениях](../docs/measurements.md).
