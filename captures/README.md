# Исходные захваты

`raw/` содержит исходные PulseView `.sr`, настройки просмотра `.pvs` и
UART-захват RST. Эти файлы — доказательная база протокола, а не сборочные
артефакты. `.pvs` не заменяет `.sr` с отсчётами.

| Файлы в `raw/` | Сценарий |
|---|---|
| `00_j8_power_on_idle.*` | Запуск и idle |
| `01_j8_up_500ms.*`, `02_j8_down_short.*` | UP/DOWN и отпускание |
| `03_j8_sit.*`, `04_j8_stand.*` | Штатный recall |
| `05_j8_sleep_first_up.*`, `06_j8_sleep_wake_then_up.*` | Сон и первое касание |
| `07_j8_up_click_awake.*` | Короткий UP |
| `08_j8_clicks_98cm.*`, `08_j8_clicks_105cm.*` | Шаги по обе стороны от 100 см |
| `09_j8_stand_115cm.*`, `10_j8_stand_recall_115cm.*` | Сохранение и вызов STAND |
| `11_j8_sit_80cm.*`, `12_j8_sit_recall_80cm.*` | Сохранение и вызов SIT |
| `13_j8_rst_uart.log`, `13_j8_rst_uart.raw.log` | Сброс штатным пультом |
| `14_20261003_production_journal.bin`, `.txt` | Постоянный журнал первого прогона; [результаты](../docs/test-run-2026-10-03.md) |

У логического анализатора D0 подключён к J8-2 (панель → стол),
D1 к J8-3 (стол → панель), GND общий, VCC не подключён.
Записи `.sr` сделаны при 1 МГц; декодирование — UART 9600/8N1.

Из корня репозитория:

```sh
python3 tools/decode_sr.py captures/raw/00_j8_power_on_idle.sr
```

Утилита рассчитана на формат этих захватов: `logic-1-1` и каналы D0/D1.
Для другой частоты использовать `--sample-rate`; это не универсальный
конвертер всех форматов PulseView.

Выводы сведены в [протокол](../docs/protocol.md), наблюдения — в
[историю измерений](../docs/measurements.md). Новые дампы постоянного журнала
снимать через [desk_log.py](../docs/persistent-journal.md): формат `.bin`
не совместим с `.sr`.
